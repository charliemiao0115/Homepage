Selected work at OMNIVISION

Four perception models I built and shipped onto OMNIVISION silicon. Each one has a power, latency and memory budget it has to meet.

dms · 68 landmarks OAX4600 · NPU
01 / Driver monitoring

Driver Monitoring System

An ultra-low-power facial landmark model for a production-grade driver monitoring system. I used aggressive quantisation and pruning to meet strict power, latency and memory limits, and kept it accurate across diverse lighting and head poses.

Platform OMNIVISION OAX4600 ↗: an AI-enabled ASIC for driver and occupant monitoring that pairs an RGB-IR ISP with a dedicated 2 TOPS NPU.

02 / Gesture

Hand Gesture Recognition

A gesture recognition model built for embedded deployment. It recognises gestures reliably in real time within tight compute and memory budgets.

Platform OMNIVISION OG12B10: a 12 MP image sensor with an NPU attached directly to the sensor, so vision models run right where pixels are captured.

03 / Barcode & QR

Barcode & QR Detection

A custom lightweight CNN detector designed for fixed-point quantisation and hardware post-processing. It detects reliably at ultra-low power, with detection decoding I wrote in C on RISC-V.

Platform OMNIVISION OG12B10, running on the NPU attached to the sensor.

04 / Person detection

Person Detection

An always-on person detection model for vehicle security, small enough to keep watching while the rest of the car sleeps.

Platform OMNIVISION OAX7700 ↗: an ultra-low-power AI companion processor with an integrated NPU for always-on parking surveillance.

How a model reaches silicon

scroll →
  1. 01

    Architect

    Custom lightweight CNNs, designed around the compute, memory and power budget of the target hardware.

  2. 02

    Train

    PyTorch and JAX/Flax, made robust to diverse lighting, head poses and real-world noise.

  3. 03

    Compress

    Aggressive fixed-point quantisation and pruning that keep the accuracy.

  4. 04

    Convert

    I own model conversion to the hardware format, working with the ASIC team on OMNIVISION's latest NPU and its CNN post-processing hardware.

  5. 05

    Post-process

    Detection decoding written in C on a RISC-V processor, joining inference and output decoding into one on-device system.

  6. 06

    Ship

    Real-time, production-grade perception running at ultra-low power, on device.
